## ⚠️ **注意事项**

1. **API密钥安全:** 使用环境变量，不要硬编码
2. **网络稳定性:** 云服务器网络一般比家用网络更稳定
3. **时区设置:** 确保服务器时区设置正确
4. **自动重启:** 配置进程监控和自动重启
5. **日志管理:** 定期清理日志文件避免磁盘满

## 🚀 **快速开始 (推荐Oracle Cloud)**

```bash
# 1. 克隆项目到云服务器
git clone [your-repo] trading_bot
cd trading_bot

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置环境
cp config.env.example .env
# 编辑.env文件添加API密钥

# 4. 启动系统
nohup python main.py > trading.log 2>&1 &

# 5. 检查状态
tail -f trading.log
```
