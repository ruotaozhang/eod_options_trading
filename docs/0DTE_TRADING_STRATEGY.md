# 📊 末日期权(0DTE)交易策略指南

## 🎯 期权选择策略（基于代码实际逻辑）

### **实际系统策略：价格就近选择**

#### **选择逻辑**
```
Call期权：选择floor(当前价格)行权价
Put期权：选择ceil(当前价格)行权价  
示例：当前SPY价格$599.26
     Call期权：选择$599行权价
     Put期权：选择$600行权价
```

#### **优势分析**
- ✅ **简单明确**：不依赖复杂的希腊字母计算
- ✅ **快速执行**：直接基于当前价格选择最近行权价
- ✅ **无需外部数据**：仅需要标的资产当前价格
- ✅ **低延迟**：避免delta计算带来的延迟

## 📈 系统特点对比

### **2. 信号生成逻辑 🔄**
```
ORB突破信号：
• 价格突破开盘15分钟高/低点
• 成交量 > 基准成交量 × 1.2倍
• RSI > 60（多头）或 < 40（空头）

VWAP偏离信号：
• 价格偏离VWAP > 0.15%
• 持续3分钟确认
• MACD柱状图同向确认

反转信号：
• 尾盘时段（14:30-15:00）
• RSI超买/超卖反转
• 支撑阻力位确认
```

### **期权选择实现**
```python
def find_suitable_options(symbol: str, option_type: str):
    current_price = get_current_price(symbol)
    
    if option_type == 'CALL':
        target_strike = int(current_price)  # floor操作
    else:
        target_strike = int(current_price) + (1 if current_price > int(current_price) else 0)  # ceil操作
    
    # 直接生成期权代码，不进行额外筛选
    option_symbol = generate_option_symbol(symbol, target_strike, option_type)
    return get_option_snapshot(option_symbol)
```

## 📊 实战执行流程

1. **信号检测**：多策略并行检测交易信号
2. **期权选择**：基于当前价格选择最近行权价期权
3. **风险检查**：验证交易限制和风险额度
4. **下单执行**：限价单买入期权合约

3. **强制平仓**：15:45时间止损避免行权风险

## 🚀 策略执行要点

### **开仓条件**
1. **信号确认**：ORB/VWAP/反转信号任一触发
2. **期权选择**：当前价格floor/ceil行权价
3. **时间窗口**：09:30-15:45
4. **风险验证**：通过所有风险检查

### **持仓管理**
1. **高频监控**：5秒更新价格
2. **实时计算**：动态更新未实现盈亏
3. **快速响应**：止盈止损立即执行

### **平仓原则**
1. **止损触发**：价格 ≤ 入场价 × 90%
2. **止盈触发**：价格 ≥ 入场价 × 120%
3. **时间止损**：15:45强制平仓
4. **紧急平仓**：系统异常时应急处理
