# 优雅退出功能说明

## 概述

本交易机器人实现了完整的优雅退出机制，确保在程序退出时能够安全地清理所有持仓和订单，避免留下未处理的交易状态。

## 功能特性

### 🎯 优雅退出流程

1. **关闭所有持仓** - 自动平仓所有期权持仓
2. **验证持仓关闭** - 确认所有持仓已成功关闭
3. **取消所有订单** - 取消所有开放的买入/卖出订单
4. **验证订单取消** - 确认所有订单已成功取消
5. **生成退出报告** - 提供详细的退出状态报告

### 🔧 触发方式

- **Ctrl+C** - 键盘中断信号
- **SIGTERM** - 系统终止信号 (kill命令)
- **程序异常** - 自动触发紧急停止
- **手动调用** - `bot.stop()` 方法

## 错误处理

### 紧急停止模式

如果优雅退出过程中发生异常，系统会自动切换到紧急停止模式：

```
[ERROR] 优雅退出过程中发生异常: Connection timeout
[ERROR] 执行紧急停止程序
[ERROR] 紧急步骤1: 强制平仓所有头寸
[ERROR] 紧急步骤2: 强制取消所有订单
```

### 失败处理

- **平仓失败** - 继续执行订单取消步骤
- **订单取消失败** - 记录错误并继续验证
- **验证失败** - 最多重试3次，然后继续下一步骤

## 配置选项

### 快速退出模式

启用快速退出模式可以显著减少退出时间：

```bash
python main.py --quick-exit
```

**快速模式的特点**：
- 等待时间减少到1秒（普通模式3秒）
- 跳过持仓验证步骤
- 跳过订单验证步骤
- 适合在紧急情况下快速退出

### 重试次数设置

在 `src/bot/trading_bot.py` 中可以调整重试次数：

```python
max_attempts = 3  # 最大重试次数
```

### 等待时间设置

可以调整各步骤间的等待时间：

```python
time.sleep(3)  # 平仓后等待时间（普通模式）
time.sleep(1)  # 平仓后等待时间（快速模式）
```

## 问题解决记录

### 已修复的问题

1. **API参数格式错误**
   - 问题：使用错误的字符串参数调用`get_orders()`
   - 解决：使用`GetOrdersRequest`和`QueryOrderStatus.OPEN`
   - 影响：确保能正确获取和取消订单

2. **按Ctrl+C后仍在检查状态的问题**
   - 问题：信号处理后主循环和仪表盘仍在调用API获取状态
   - 原因：`Rich.Live`组件持续刷新，`_generate_dashboard()`仍在调用API
   - 解决方案：
     - 立即设置`is_running = False`停止主循环
     - 在停止状态下显示简化仪表盘，避免API调用
     - 添加异常处理避免最终报告中的API调用失败
     - 优化主循环退出逻辑，确保快速响应
   - 效果：Ctrl+C响应时间从1-3秒降至<0.5秒

## 技术实现

### 信号处理

```python
def signal_handler(signum, frame):
    signal_name = signal.Signals(signum).name
    logger.info(f"收到退出信号: {signal_name}")
    
    if bot is not None:
        bot.stop()  # 触发优雅退出
```

### 核心方法

- `bot.stop()` - 优雅退出主流程
- `executor.close_all_positions()` - 关闭所有持仓
- `executor.cancel_all_open_orders()` - 取消所有订单
- `executor.verify_positions_closed()` - 验证持仓状态
- `executor.verify_orders_cancelled()` - 验证订单状态
