# 演示脚本

本目录包含用于演示各种功能的脚本。

## 脚本说明

### 优雅退出演示

- **`demo_graceful_shutdown.py`** - 优雅退出功能演示
  - 展示完整的退出流程
  - 演示如何响应退出信号
  - 适合新用户了解功能

- **`demo_quick_exit.py`** - 快速退出模式演示
  - 演示快速退出模式的使用
  - 展示跳过验证步骤的退出
  - 对比不同退出模式的效果

## 运行方式

```bash
# 从项目根目录运行
python tests/demos/demo_graceful_shutdown.py
python tests/demos/demo_quick_exit.py
```

## 使用场景

- **学习功能** - 了解优雅退出的工作原理
- **功能演示** - 向他人展示系统功能
- **集成测试** - 验证完整的用户流程
- **培训材料** - 用于团队培训

## 注意事项

- 演示脚本会实际连接到Alpaca API
- 建议在测试环境中运行
- 观察日志输出了解详细流程
